How it works
  • The college's API key stays on the server; students never see it.
  • Draft checks are not added to the iThenticate repository, so your final submission will not match your own drafts.
  • Quotes and bibliography are excluded from the score.
  • The portal keeps only the file's SHA-256 fingerprint and the score, not the file.
  • Each result has a DC- code that faculty can verify.
